# XFEM figure standard

## Required

- Use a fixed STATUSXFEM range of 0-1 when STATUSXFEM is encoded by color.
- Keep the reference Shell visually subordinate to the result.
- Use one dedicated colorbar band and check text/colorbar bounding boxes.
- Save detailed spatial figures at 500 dpi and other publication figures at no
  less than 450 dpi.
- Verify all raster and vector outputs and inspect at original resolution.

## Interpretation

A connectivity line shows adjacency and path, not physical opening. Marker
size and line width are presentation variables. State when any geometry crop is
display-only and leave extracted result values unchanged.
